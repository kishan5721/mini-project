B.Tech Mini Project • Frontend Web Development

Student Task & Study Planner

A modern, responsive, client-side web application designed to help undergraduate college students organize coursework, manage submission deadlines, and monitor daily academic productivity.

🎯

Project Objectives

  • Provide an intuitive, distraction-free interface for scheduling study sessions.
  • Eliminate missed academic deadlines through color-coded priority and urgency alerts.
  • Encourage consistent daily study habits via real-time completion analytics.
  • Guarantee offline capability and zero backend maintenance via Web Storage API.
⚡

Key Features & Functionalities

  • Dynamic Dashboard: Live statistical metrics, completion percentages, and daily tips.
  • CRUD Capabilities: Add, edit, mark complete, and delete tasks with safe confirmations.
  • Multi-faceted Search & Filters: Instant search by name, subject, priority, and status.
  • Light & Dark Themes: User preference auto-saved in local storage.
  • Zero Dependencies: 100% pure HTML5, CSS3, and modern ES6+ JavaScript.
💻

Technology Stack

HTML5 Semantic Layout CSS3 Custom Properties & Flex/Grid JavaScript ES6+ (Modules & DOM) LocalStorage API Client-Side Persistence SVG Icons Lightweight & Crisp
🛠️

Data Management & Persistence

The application serializes task objects into standard JSON arrays stored under the key studyPlanner_tasks_v1. Every state modification instantly writes to the storage layer, ensuring zero data loss upon browser refresh or tab closure.

🎓 College Mini Project Evaluation Notes (Viva Cheat-Sheet)

1. How does the application store data without a SQL/NoSQL backend?

The system utilizes the browser's native HTML5 Web Storage API (LocalStorage). Tasks are stored as key-value pairs where the value is a JSON string. The JSON.stringify() method is used to persist data, and JSON.parse() reconstructs the JavaScript object model during initialization.

2. How is single-page navigation achieved without React or Angular?

Navigation is driven by data attributes (data-section="...") and event delegation. When a nav link is clicked, the script toggles CSS active classes across corresponding <section> elements while updating sidebar highlight states without triggering full page reloads.

3. What client-side input validation is implemented?

The application checks for non-empty task titles, valid subject selections, and valid calendar dates before creating or updating tasks. Inline error messages and CSS state classes provide immediate visual feedback to the user.
